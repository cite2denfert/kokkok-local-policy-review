# 데이터 노트 (원본 검증과 R07 계산 정의)

## 1. 원본 데이터

- 원본 파일: `ABP_CONTEST_DATA.csv` (공모전 제공, 재배포 불가)
- 검증일: 2026-09-16
- 242,574행 × 9열, 기간 2026-01 ~ 2026-06
- 시도 17개, 시도·시군구 조합 255개, 업종 11개(식음료·생활유통 위주)
- 열: `STRD_YYMM`, `SIDO_NM`, `CCG_NM`, `TP_BUZ_NO`, `TP_BUZ_NM`, `GENDER_CD`, `AGE_CD`, `amt`, `cnt`

## 2. 원본 검증 결과 (`src/01_check_data.py`)

- `GENDER_CD`: 1, 2, 3(외국인), x(미상)
- `AGE_CD`: 1~6, x(미상). 성별 x와 연령 x는 같은 행이다
- `amt`·`cnt` 숫자 변환 실패 0, 완전히 같은 중복 행 0
- 업종명은 `편 의 점`, `슈퍼 마켓`, `제 과 점`처럼 띄어 쓰여 있어 계산에서는 업종 코드(`TP_BUZ_NO`)로 이름을 붙인다
- 연령 코드 1은 설명서상 "20대 이하"이며 주민등록 인구의 20세 미만에 대응시켰다(결제 비중 1.0% vs 20세 미만 주민 비중 14.7%)

## 3. R07 계산 정의 (`src/02_make_r07.py`)

| 기호 | 뜻 | 계산 |
| --- | --- | --- |
| F | 외국인 결제금액 | `GENDER_CD`=3 행의 `amt` 합 |
| T | 전체 결제금액 | 같은 범위 모든 행의 `amt` 합 |
| U | 성별 미상 결제금액 | `GENDER_CD`=x 행의 `amt` 합 |
| C | 거래건수 | 같은 범위 `cnt` 합(고객 수가 아니라 거래건수) |

- 외국인 비중 = F / T × 100
- 미상 비중 = U / T × 100
- 미상 제외 외국인 비중 = F / (T − U) × 100

## 4. 주요 결과 (`src/03_compare_r07.py`)

2026년 1~6월 인접 월 5개 구간에서 외국인 결제금액과 전체 분모 기준 외국인 비중의 변화 방향이 모두 달랐다. 3월→4월 비중 변화는 약 +0.0076%p로 매우 작아 방향은 표시하되 변화폭을 과장하지 않는다. 이 결과를 다른 기간·지역에도 적용되는 일반 법칙으로 해석하지 않는다.

## 5. 해석 원칙

- 외국인 결제금액 증가와 외국인 비중 증가는 서로 다른 의미다.
- 외국인 비중이 잘못된 지표라는 뜻은 아니다. 사업 목표가 금액 확대인지 비중 확대인지 먼저 확인한다.
- 비중 변화만으로 사업의 인과효과를 판단하지 않는다.
- 미상 제외 비중을 더 정확한 정답으로 간주하지 않는다.
- 전국 자료를 특정 지역 진단처럼 표현하지 않는다.
- 데이터가 없다는 것을 소비가 0이라는 뜻으로 해석하지 않는다.
- 시군구는 가맹점 소재지 기준으로 간주했다(결제금액과 인구의 로그 상관 0.94, 1인당 결제액은 시군구 간 최대 약 16배 차이로 상위가 도심 구·관광지).

## 6. 개발 연결 규격

- 금액은 원 단위 정수(KRW), 비중은 퍼센트 값 그대로(7.35% → 7.35), 월은 `YYYY-MM`
- 전국 기록의 `region_key`는 `ALL`, 2026-01~06 모든 월을 생략 없이 포함
- 인접 월 비교는 서비스가 F·T·U로 다시 계산하고, 분석 쪽 `03_compare_r07.py` 결과는 독립 검산용으로 유지
- 2026-09-17 서비스 연결 검증: 로더 통과, 스키마 경고 없음, 비교 A·B 5개 구간 모두 분석 쪽 검산과 일치, R07 질문 정상 생성
