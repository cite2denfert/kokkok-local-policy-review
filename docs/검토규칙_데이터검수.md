# 검토 규칙 데이터 담당 검수 (2026-09-17)

서비스의 검토 규칙이 데이터로 말할 수 있는 범위를 넘지 않는지 데이터 담당이 검수한 기록이다.

| 규칙 | 실행 조건 | 결과 | 검수 의견 |
| --- | --- | --- | --- |
| R01 목표와 사용처 | 목표에 "참여 상점 이용 확대"가 있고 쿠폰 사용처가 비어 있을 때 | 사용 가능 | 데이터로 특정 상권·점포를 추천하는 것이 아니라 운영 조건 누락을 확인하는 수준. 카드 데이터가 상권·점포 적합성을 판정하는 것처럼 표현하지 않는다 |
| R03 대상과 자료 | 사업 대상에 관광객·방문객·여행객이 있고 성과지표가 외국인 카드 결제금액·비중일 때 | 사용 가능 | 외국인 카드 지표는 외국인 전체이며 관광객을 따로 구분하지 않는다. "자료가 잘못됐다"가 아니라 "대상과 자료의 범위가 다를 수 있다"는 확인 질문으로 유지한다 |
| R04 기간 | 사업 기간이 31일 미만이고 카드 지표를 직접 성과평가에 쓸 때 | 조건부 사용 가능 | 월 단위 집계라 짧은 사업과 기간이 맞지 않을 수 있다. 31일은 통계적 임계값이 아니라 서비스의 구현 기준임을 문서에 명시한다 |

## 문서 반영 문장

- R01: 사용처 범위를 확정 항목으로 추가하는 문장은 사용 가능. 목표에서 참여 상점 이용 확대를 빼는 것은 사용자가 그 대안을 직접 고른 경우에만 반영한다.
- R03: "성과 자료는 외국인 전체 기준이며 관광객과 거주 외국인을 구분하지 않음"은 사용 가능. 관광객 소비의 직접 분석 결과처럼 표현하지 않는다.
- R04: 카드 지표를 참고 자료로 두고 사업 기간 성과를 별도로 확인하도록 하는 문장은 사용 가능. 월별 카드 자료만으로 단기 사업의 인과효과를 판단하는 표현은 쓰지 않는다.

## AI 참고 의견에 넘기는 상황 설명

- 실제 카드 금액·비중·건수를 LLM에 전달하지 않는다.
- 실제 데이터에서 확인한 범위보다 강한 결론을 만들지 않는다.
- 성공·실패·오류·위험 같은 판정 표현을 쓰지 않는다.
- 사업 시행과 카드 소비 변화 사이의 인과관계를 주장하지 않는다.
- 규칙 결과에 대한 확인 사항만 참고 의견으로 제시한다.
